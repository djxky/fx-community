# 资源详情页 v2 设计

## 目标

在保留资源详情页现有数据与操作语义的前提下，重排首屏信息，让老师先看到资源预览、作者、简介和核心操作；评论默认不占据正文空间，但仍能在同一页面右侧直接展开查看。当前版本已保存为 `resource-detail-v1` checkpoint，新方案只在 Vue 源码中迭代，不自动覆盖 `飞象社区原型-vue.html`。

## 首屏布局

桌面端使用左大右小的双栏布局：左侧是资源或应用预览，右侧是详情栏。详情栏默认展示标题、作者、创建时间、原创或改编署名、简介和应用数据。应用数据保留累计使用次数图表，不因评论收起而删除。

预览下方保留作者与使用统计，并放置核心操作。资源继续提供收藏、分享、改编、下载；客态应用提供收藏、分享、改编、复制副本；主态应用提供收藏、分享、编辑。原创与改编不改变操作集合，改编状态继续展示原作者信息。

## 右侧详情与讨论切换

详情栏顶部提供轻量的“详情 / 讨论”切换。默认停留在“详情”，评论不会直接铺满首屏。点击评论数或“讨论”后，右侧栏原地切换成评论列表，不使用弹窗或抽屉，也不离开当前详情页。讨论栏顶部可保留资源动态，评论列表继续完整保留并独立滚动。

移动端将左侧预览置于上方，右侧详情栏变为预览下方的页签区域；简介、应用数据与讨论仍通过页签访问，应用数据不隐藏。

## 第二屏内容

版本与改编从首屏下移，优先展示有价值的改编版本和可追溯的原创作者链路。原有关于内容、版本内容和改编卡片数据继续复用，不新增跳转流程。

## 原型预览控制

主态/客态、资源/应用、原创/改编的 8 种组合继续由数据驱动生成。状态预览控制从首屏主体移到小型“预览控制”入口，避免干扰真实详情布局；预览状态仍可通过 URL 恢复，关闭后回到真实资源数据。

## 范围与边界

- 本版本只调整资源详情页布局和展示层交互，不修改资源数据模型与操作权限。
- 不实现评论提交、评论删除、评论置顶等后端能力。
- 不删除应用数据，也不把评论内容永久移除。
- 不同步生成的正式 HTML，不提交或发布到线上，除非后续单独确认。

## 验证

实现后需要验证：桌面端首屏双栏布局、详情/讨论原地切换、应用数据图表、原创/改编署名、8 种状态预览、移动端换行与滚动，以及现有资源相关测试和生产构建。
