# 资源详情页

> 版本 v1.4 · 教师社区

## 1. 资源预览区

展示：资源预览、页码、缩放、全屏。

交互（demo 已实现，从简）：
- 多页课件：左缩略图轨 + 右主预览；点缩略图 → 主预览切到该页，页码同步
- 单页资源：封面铺满，不裁切、无缩略图轨
- 应用：运行态预览

规则：按资源类型分预览形态（多页课件 / 单页资源 / 应用）；课件底部页码「课件 · 当前页 / 总页数」。

异常 / 空状态：
- 预览图加载失败 → 占位底色 + 资源标题首字兜底，页面不塌；占位图样式设计待补
- 应用运行 / 加载失败 → 预览区「加载失败，点击重试」，点击重新加载
- 资源已下架 / 无权限 → 预览区「该资源暂不可用」，隐藏下载 / 改编
- 课件 0 页 / 内容缺失 → 空状态「暂无预览内容」


## 2. 资源标识区

展示：标题、（应用）类型图标、作者（认证标）、适配信息（学科 · 年级 · 教材 · 课型 · 类型）、使用数、收藏数、操作按钮组。

交互：
- 收藏（demo 已实现）：无人收藏 → 显示五角星 +「收藏」；有人收藏 → 显示五角星 + 收藏数。点收藏 → 收藏数 +1、五角星填充黄色、弹 toast「收藏成功，可前往「我的知识库」查看」，点该 toast 直接跳转「我的知识库」；再点 → 取消收藏、数 -1、五角星恢复空心
- 改编（demo 已实现）：点改编 → toast「已为你创建改编副本，正在进入改编…」，进改编流程
- 下载（demo 已实现）：点下载 → toast「开始下载资源包…」
- 复制副本（应用 · 客态，demo 已实现）：toast「已复制副本到「我的空间」」
- 分享：点分享 → 唤起分享面板（复制链接 / 二维码），复制成功 toast「链接已复制」

规则（操作按钮组随类型 / 身份变）：
- 资源：收藏 · 分享 · 改编 · 下载
- 应用 · 客态：收藏 · 分享 · 改编 · 复制副本
- 应用 · 主态：收藏 · 分享 · 编辑
- 应用类资源标题前置类型图标；纯资源无图标
- 适配信息某项缺失（如无课型）→ 该项连同分隔点省略，不留空位

异常 / 空状态：
- 未登录点下载 / 改编 / 收藏 → 引导登录，登录后继续原操作
- 网络失败 → toast「网络异常，请重试」，按钮恢复可点
- 下载中重复点击 → 按钮置灰 loading，防重复触发
- 作者无认证 → 不显示认证标，仅作者名


## 3. 简介（含创作来源、所属专题）

展示：简介正文；改编资源额外展示「引用原作」卡（原作名、原作者、被引用版本、查看原作入口）；属于专题时末尾展示「所属专题」标签。卡内自上而下：简介正文 →（改编才有）引用原作卡 →（有专题才有）所属专题标签。

交互：
- 点引用原作卡 → 进原作详情页
- 点所属专题标签 → 进该专题合集页

规则：
- 原创资源不展示引用原作卡（仅改编展示）
- 不属于任何专题时不展示专题标签、不占位

异常：原作已删除 / 下架 → 引用卡降级为纯文字署名「原作已不可用」，不可点，不给死链。


## 4. 优质改编

展示：基于本资源的改编列表（封面缩略图、标题、改编者、使用人数），区块标题右侧「N 个改编」计数。

交互：
- hover 卡片 → 浮现「查看」按钮
- 点卡片（整行）→ 进该改编详情页
- 超出首屏时，底部「查看全部 N 个改编」→ 进本资源的改编列表页

规则：首屏展示 3 条，按使用人数倒序；超过 3 条显示「查看全部」入口。（当前 demo 按配置顺序展示、未截断，排序 / 条数上线前与研发确认。）

异常 / 空状态：
- 暂无改编 → 整个模块不展示（不占位、不显示空态；空模块只有「讨论」保留空态）
- 改编封面缺失 → 占位底色 + 标题首字兜底


## 5. 最近动态

展示：本资源行为流（谁改编 / 收藏 / 下载了 + 时间）。

交互：横向滚动跑马展示。

规则：展示最近 20 条，滚动循环播放；动作类型分改编 / 收藏 / 下载三种图标。

异常 / 空状态：
- 暂无动态 → 整块不展示
- 拉取失败 → 静默重试，不弹错、不打断页面


## 6. 讨论

展示：讨论列表（头像、昵称、内容、时间、嵌套回复），底部输入区（「说点什么…」）。

交互：
- 发评论：点「评论 / 说点什么」→ 右栏平滑定位到讨论第一条 + 底部展开输入面板（输入框 + 取消 / 发送，此时"评论 / 分享"隐藏、输入框聚焦）→ 点发送 → 评论进列表首位、讨论数 +1、面板收起
- 回复：某条评论 / 回复下点「回复」→ 复用底部同一输入框、进入回复态（输入框上方加一块「回复 @某某」+ 被回复评论内容引用一行，取消 / 发送同直接评论）→ 发送 → 以子级嵌套挂在该评论下、讨论数 +1。评论与回复共用一个输入框，互斥：点「说点什么」或另一条「回复」即切换目标
- 置顶（仅作者）：作者在某条评论上点置顶 → 该评论上浮列表首位、加「置顶」标；再点 → 取消置顶、回到时间序
- 删除（作者删任意 / 本人删自己）：点删除 → 移除该评论及其全部回复，讨论数相应减少

规则：
- 列表按发布时间倒序，置顶评论固定最前
- 首屏加载 10 条，向下滚动触底自动加载下一批 10 条（加载时底部转圈动画，无「加载更多」按钮），全部加载完显示「没有更多了」
- 评论内容上限 500 字
- 时间显示：**1 周内用相对时间**——刚刚（<1 分钟）/ N 分钟前 / N 小时前（今天）/ 昨天 时:分（如「昨天 08:12」）/ N 天前（前天起 7 天内）；**超过 1 周直接显示日期**——同年「月-日」（如「08-13」），跨年「年-月-日」
- 回复他人的回复时，正文前缀「回复 @某某」（回复顶层评论不加前缀）
- 点「回复 / 说点什么」进入输入态时，讨论列表保持当前滚动位置，内容不跳动（输入框在底部就地展开）
- 权限见「权限矩阵」
- （当前 demo 为种子 3 条、无真实分页，触底会转圈一次后到底；时间为写死的相对文案）

异常 / 空状态：
- 空内容点发送 → 发送按钮置灰、不可提交（面板保持展开）
- 仅空格 / 换行 → 同空内容处理，不可提交
- 未登录点发送 → 引导登录，登录后回填草稿
- 超长（超过 500 字）→ 输入框下提示「评论最多 500 字」，超出部分不可再输入
- 发送失败（网络异常）→ toast「发送失败，请重试」，草稿保留、可重发
- 删除二次确认 → 弹确认「删除后不可恢复，确认删除？」，确认才删
- 暂无评论 → 空状态「来说两句，抢个沙发」


## 权限矩阵（主态 / 客态）

| 能力 | 客态（普通老师） | 主态（作者本人） |
| 改编 / 下载 / 复制副本 | ✅ | ✅ |
| 收藏 / 分享 | ✅ | ✅ |
| 发评论 / 回复 | ✅ | ✅ |
| 删除评论 | 仅自己的 | 任意 |
| 置顶评论 | ❌ | ✅（仅顶层） |
| 编辑（应用） | ❌ | ✅ |
| 作者发言标识 | — | 金色「作者」标 |
| 查看数据 | ❌ | [!] 规划中 |

## 分支逻辑（同一页面按形态分流）

- 内容：资源 / 应用（应用为运行态预览、标题前置图标、操作含复制副本 / 编辑）
- 身份：客态 / 主态（主态多编辑，讨论区多置顶 / 删任意）
- 来源：原创 / 改编（改编在简介多「引用原作」卡）
- 专题：有 / 无（有专题在简介末尾多「所属专题」标签）
- 形态：多页课件 / 单页资源 / 应用（预览区呈现不同）
