# 资源详情页

> 版本 v1.1 · 教师社区 · ResView（`?view=res&resource=<id>`）
> 说明：原型为静态演示。已实现的交互标注「demo 已实现」；登录门槛、网络异常等**边界态为产品规格**，静态原型未拦截。字段带英文 key，跳转写明目标页。

## 背景

老师打开一个资源详情页，脑子里只有一个问题：**这份资源能不能用到我的课上、怎么用？** 旧版更像"作品展示页"，把老师做决策要的硬信息（年级、教材、课型、多少人用过）散在各处。这一版把它改造成"选课备课决策页"：首屏走完 **适配我吗 → 好不好·多少人用 → 拿来用/改**。左栏 = 决策信息 + 操作，右栏 = 详情 + 社交。

## 0. 详情状态预览器（原型演示器 · 非线上）

**功能说明**：顶部居中的状态切换器，评审时在同一原型里切不同形态/身份看页面变化。**只服务过稿演示，线上不存在。**

**交互流程**：`内容 contentType`（资源/应用）、`视角 viewer`（客态/主态）、`来源 source`（原创/改编）三维可切；「还原真实数据」回到该资源真实态。切换写进 URL query，便于分享某一形态。

**业务规则**：`isAuthorView() = 预览器开 且 viewer==='owner'`；线上主态由 `author.accountId` 与登录用户比对。

**关联模块**：`viewer`→[2] 操作集/[7] 讨论权限；`source`→[4] 引用原作卡；`contentType`→[1] 预览形态/[2] 应用图标。

**不做**：不进生产包。

## 1. 左侧 · 资源预览区

**功能说明**：占左栏主高度，把资源本体大面积展示，让老师先"看到货"。

**交互流程**（demo 已实现，从简）：
- 多页课件（`kind` 含"课件"）：左缩略图轨 + 右 16:9 主预览；点缩略图 → 主预览切到该页、页码同步。
- 单页资源：封面 `contain` 铺满、不裁切、无缩略图轨。
- 应用：运行态预览，底部标签 `<类型> · 运行预览`。
- 底部工具条：页码（课件为 `课件 · 1 / N`）、缩放、全屏。

**业务规则**：`isSlideResourceKind(kind)` 判定"缩略图+主预览"还是单页 `contain`；`kind` 含 `/` 时取末段展示（`剧本杀/课件`→`课件`）。

**数据说明**：预览图取 `cover`，缺省回退 `COVERS[0]`。

> 数据口径：课件缩略图轨当前为固定 6 页占位（封面/情境/探究/建模/练习/小结），页码 `1 / 6` 亦占位；接线后取真实页数 N。

**异常场景 / 空状态**：
- `cover` 加载失败 → 占位底色 + 资源标题首字兜底，不塌。
- 资源已下架 / 无权限（产品规格）→ 预览区「该资源暂不可用」，隐藏下载/改编。
- 课件 0 页 / 内容缺失（产品规格）→「暂无预览内容」。

**关联模块**：预览封面与 [5] 优质改编卡缩略图共用同一张 `cover`。

**不做**：不做在线编辑、不做逐页播放；全屏仅放大查看，非课堂放映。

## 2. 左侧 · 资源标识区

**功能说明**：预览下方两行核心信息 + 一排操作，老师 3 秒决策落点。两行——一眼抓到"是什么 + 谁做的 + 适不适配我"，再多即负担。

**交互流程**：
- 第 1 行 · 标题：应用类前置大图标（`res-order-game`→🍽️，余→✦），纯资源直接标题。
- 第 2 行 · `作者 ✓ ┃ 适配条`：作者（认证打勾）与适配条竖线分隔。
- 适配条：`学科 · 年级 · 教材 · 课型 · 类型`，「·」分隔、去重。
- 操作行（数据贴主操作）：`👥 use 使用　☆ star 收藏　[改编]　[下载/复制副本/编辑]`。
- 收藏（demo 已实现）：星标变金、收藏数 +1、「收藏」→「已收藏」，再点取消。
- 改编（demo 已实现）：toast「已为你创建改编副本，正在进入改编…」，真实态进改编器、新作 `forkedFrom` 指向本资源。
- 下载（demo 已实现）：toast「开始下载资源包…」。
- 复制副本（应用客态，demo 已实现）：toast「已复制副本到「我的空间」」。

**业务规则**：操作集由 `getResourceActions({contentType,isOwner})` 决定——
- 资源：收藏·分享·改编（次）·**下载**（主）
- 应用·客态：收藏·分享·改编·**复制副本**（主）
- 应用·主态：收藏·分享·**编辑**（主）

**数据说明**：适配条取 `fit.subject / fit.grade（「·」末级）/ fit.textbook / fit.lessonType` 与 `kind`，去重拼接。

> 数据口径：`stats.use/star/adapt` = 使用/收藏/改编数；收藏按钮实时展示 `star + starDelta`（本地叠加），`use` 只读。

**异常场景 / 空状态**（多为产品规格，静态原型未拦截）：
- 未登录点下载/改编 → 引导登录。
- 网络失败 → toast「网络异常，请重试」，按钮恢复可点。
- 下载中重复点击 → 按钮置灰 loading，防重复触发。
- 字段缺失（如无课型）→ 该段连同分隔点省略，不留空「·」。

**关联模块**：收藏（数据）在左、[7] 讨论的分享（社交）在右，不重复；`isOwner` 与 [0] `viewer` 联动决定按钮组。

**不做**：`[!]` 适配条暂不含"课时"——`fit` 无该字段，待数据层补齐。

## 3. 右侧 · 所属专题 [UPDATED]

[~] v1.1：从右栏顶部移入简介卡内（正文/引用原作卡之下），归为简介的一部分。

**功能说明**：接在简介正文下方的一枚轻胶囊标签，标明本资源所属策展专题合集，给"同类还有更多"的入口。

**交互流程**：点击 → 进该专题合集页（同类聚合浏览）。

**业务规则**：仅当有 `topicMembership` 时渲染；无则不占位。

**数据说明**：文案 = `topicMembership.title`（如「整本书阅读 · 经典重构」）。

**异常场景 / 空状态**：无 `topicMembership` → 整枚不渲染。

**关联模块**：归入 [4] 简介卡内——所属专题本就是"这份资源是什么"的一部分，贴着简介比抬到栏顶更自然。

**不做**：不在此展开专题内其它资源。

## 4. 右侧 · 简介（含创作来源）[UPDATED]

[~] v1.1：简介卡末尾承接「所属专题」标签（见 [3]），把"这份资源是什么"收拢进一张卡。

**功能说明**：资源文字介绍。卡内自上而下：**简介正文 →（改编才有）引用原作卡 → 所属专题标签**。引用原作卡是保护原创作者署名的落点。

**交互流程**：引用原作卡整卡可点 → 跳原作详情页。

**业务规则**：`forkedFrom` 为空 = 原创，不显示引用卡；有值 = 改编，显示且可跳。放"简介之后"——先看懂"是什么"再关心"改自谁"。

**数据说明**：正文取 `goal`（一句话目标）。

> 数据口径：引用卡取 `forkedFrom` 解析出的 `originalAuthorName/originalTitle`，`forkedFromVersion` 为被改编版本，文案「引用自 <作者>《<标题>》· <版本> 版本 / 查看原作 →」。

**异常场景**：原作已删除/下架 → 引用卡降级为纯文字署名（作者 + 标题）「原作已不可用」，不可点，不给死链。

**关联模块**：与 [2] 作者行分工——作者行只讲"谁做的这份"，"改自谁"由引用卡表达。

**不做**：暂不做"内容构成清单"（如 6 页课件·任务单·教师说明）。

## 5. 右侧 · 优质改编

**功能说明**：展示基于本作的优质改编，引导老师"改成我的班"。这些是本作派生版本（非随机推荐），故保留"改编"语义。

**交互流程**：每项 = 封面缩略图·标题·`作者 · use 位老师使用`；hover 才浮现「查看」；整行可点/回车（`role="link"`）→ 跳该改编详情。

**业务规则**：标题右计数 `stats.adapt 个改编`；列表来自本资源 `forks[]`。当前 demo **按 `forks` 配置顺序展示、未排序、未截断**；`[!]` 产品规格建议：首屏取 N 条、按 `use` 倒序、超出「查看全部」→ 改编列表页（排序口径待定）。

> 数据口径：`X 位老师使用` 取该改编自己的 `stats.use`，非原作。

**异常场景 / 空状态**：`forks[]` 为空 → 空状态「还没有人改编这个作品，来做第一个改编版本吧。」

**关联模块**：卡片封面复用各改编 `cover`（与 [1] 同口径）。

**不做**：本期不做筛选。

## 6. 右侧 · 最近动态

**功能说明**：本资源的行为流（谁改编/收藏/下载），给"正被同行用着"的信任感。

**交互流程**：横向滚动跑马（轨道复制一份做无缝循环），右上「● 持续更新」。

**数据说明**：每条 = `actor + action + type 图标`，`type ∈ {adapt,favorite,download}`；actor 不带"老师"时自动补「老师」。

> 数据口径：当前为默认活动列表（改编·3 分钟前 / 收藏·12 分钟前 / 下载·28 分钟前…），**首条 actor 替换成资源首位 `contributor`**；接线后换真实行为流。

**异常场景 / 空状态**：无动态 → 整块不展示，不留空标题。

**关联模块**：与 [7] 讨论同处右栏——动态是"行为"、讨论是"言论"。

**不做**：不做分页/加载更多，只滚动最近若干条。

## 7. 右侧 · 讨论

**功能说明**：精选讨论 + 参与讨论，支持发评论、回复、点赞，作者可置顶/删除。交互对标小红书评论区——轻、即时、可嵌套。

**交互流程**（demo 已实现，从简）：
- 发评论：点「说点什么…」→ 展开输入面板（大输入框 + 取消/发送，此时"评论/分享"隐藏、聚焦）→ 发送 → 进列表、讨论数 +1、自己的带「我」标。
- 回复：评论/回复下点「回复」→ 同款面板 → 发送 → 嵌套挂在其下。
- 点赞：👍 计数 ±1，可取消。
- 置顶评论上浮首位、带「置顶」标。

**业务规则**：列表按时间倒序、置顶固定最前。`[!]` 产品规格建议：首屏 N 条 +「加载更多」再 N 条、加载完「没有更多了」（当前 demo 为种子 3 条、无分页）。权限见 [8]。

**数据说明**：讨论总数 `interactions.count`（评论 + 回复），发/删同步增减。

> 数据口径：种子 3 条（含一条作者已置顶、带"作者回复"），演示置顶/作者回复形态；真实态由后端返回。

**异常场景 / 空状态**：
- 空内容点发送 → 发送置灰不可提交、面板直接收起，**不产生空评论**。
- 未登录点发送（产品规格）→ 引导登录。
- 超长（>N 字，产品规格）→ 提示「评论最多 N 字」。
- 发送失败（产品规格）→ toast「发送失败，请重试」，草稿保留。
- 删除后讨论数不为负（下限 0）。
- 暂无评论 → 空状态「来说两句，抢个沙发」。

**关联模块**：输入区常驻右栏底部（吸底）；收藏/使用数据不在此、在 [2]。

**不做**：@提及、表情、图片评论本期不做（输入面板不放这些入口）。`[!]` 图片评论是否支持待定。

## 8. 权限矩阵（主态 / 客态）

| 能力 | 客态（普通老师） | 主态（作者本人） |
|---|---|---|
| 主操作 | 改编 + 下载 / 复制副本 | 编辑（应用）/ 下载（资源） |
| 收藏 · 分享 | ✅ | ✅ |
| 发评论 · 回复 · 点赞 | ✅ | ✅ |
| 删除评论 | 仅自己的 | 任意 |
| 置顶评论 | ❌ | ✅（仅顶层） |
| 作者标识 | — | 发言带金色「作者」标 |
| 查看数据 | ❌ | `[!]` 规划中（demo 未实现） |

**业务规则**：主态判定 = `isAuthorView()`（原型走 `viewer`，线上走 `author.accountId` 比对）。

**不做**：不做协作者/编辑者等中间角色，只区分作者本人与普通老师两档。

## 分支逻辑（同一页面分流）

| 维度 | 取值 | 影响 |
|---|---|---|
| 内容 `contentType` | 资源 / 应用 | 应用在 [2] 前置图标、主操作含"复制副本/编辑" |
| 来源 `forkedFrom` | 原创（空）/ 改编（有值） | 改编在 [4] 出现"引用原作"卡 |
| 形态 `kind` | 多页课件 / 单页资源 / 应用 | [1] 走"缩略图+主预览"/"单页 contain"/"运行预览" |
