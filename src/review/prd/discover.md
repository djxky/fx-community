# 发现页

> 版本 v1.2 · 教师社区

## 1. 顶部导航

展示：页签「排行榜 / 发现」（当前选中「发现」）、搜索框（占位文案「搜知识点、课型、课件、教案…」）。

交互：
- 点「排行榜」→ 切到排行榜页
- 点「发现」→ 停留本页，无变化

[!] 搜索框在 demo 里只展示、不可点。点击后是进搜索页还是就地展开联想，待定


## 2. 灵感分类

展示：一行分类页签，顺序固定：关注 · 推荐 · 教学与备课 · 课堂与学情 · 作业与评价 · 班级与家校 · 教研与成长。

交互：交互见 demo。

规则：
- 默认选中「推荐」；同时只选中一个
- 场景页签只列有内容的场景；某场景下没有灵感 → 该页签不出现
- 切换任意页签 → 关注作者选中、具体场景 / 学段 / 学科全部重置
- 「关注」下展示关注作者行（见模块 3），不展示筛选区
- 「推荐」下既无关注作者行也无筛选区；选中场景页签才展开筛选区（见模块 4）
- 场景页签只筛推荐内容：在「关注」下点场景页签 → 切回推荐内容，按该场景筛选
- 页签超出一屏宽 → 横向滑动，不换行

异常：
- 场景分类拉取失败 → 只保留「关注」「推荐」，不报错


## 3. 关注作者

展示（选中「关注」后出现在分类下方）：一行关注对象，头像 + 名字，老师和机构都在。
- 名师头像带金色描边；无头像的显示简称或名字首字
- 名字单行，超出省略；悬停显示全名

交互：
- 点头像 → 该头像选中（深色描边、名字加粗），下方只展示该作者的资源和应用
- 点另一个头像 → 切换到该作者
- 再点已选中的头像 → 取消选中，回到全部关注对象
- 一行放不下 → 两侧出现左右箭头，点击翻页；滑到头时该侧箭头隐藏

规则：
- 进入「关注」默认不选中任何头像，下方展示全部关注对象的资源和应用
- 同一作者只出现一次；按最近动态排序，最近有动态的在前
- 离开「关注」再回来 → 回到未选中

异常：
- 头像加载失败 → 显示简称或名字首字
- 选中的作者没有公开资源 → 空状态「这位作者还没有公开的资源」
- 关注对象都没有公开资源 → 空状态「关注的作者还没有公开的资源」
- 未关注任何人、未登录 → 沿用线上关注的处理

[!] 头像排序、一行 / 一页展示多少个、未关注空状态、未登录处理沿用线上；线上关注说明文档 / 链接待补


## 4. 筛选区

展示（选中场景页签后出现在分类下方）：
- 具体场景：「全部」+ 该场景下有内容的细分场景
- 学段：「不限」+ 当前范围内出现的学段
- 学科：「不限」+ 当前范围内出现的学科
- 结果条：选了任一具体场景 / 学段 / 学科后出现，「已筛选出 N 个灵感」+「清除全部」

交互：交互见 demo。

规则：
- 默认：具体场景「全部」、学段「不限」、学科「不限」；三组各自单选，同时生效取交集
- 学段、学科选项随「场景 + 具体场景」联动，只列有内容的值；学段与学科之间不互相联动
- 切换具体场景 → 学段、学科重置为「不限」
- 该场景下没有任何细分场景 → 不展示「具体场景」行
- 点「清除全部」→ 具体场景 / 学段 / 学科回到默认，保留当前场景页签，结果条消失
- 选项一行放不下 → 自动换行

异常：
- 学段 × 学科组合无结果 → 卡片区空状态（见模块 5），筛选区保持可操作、不自动重置

[!] 分页后「N 个灵感」取筛选结果总数还是已加载条数，待定


## 5. 灵感卡片流

展示：卡片网格。卡片展示：封面、封面左上角标、标题、作者头像 + 作者名。
- 角标：推荐为「学科 · 资源类型」；关注为「学段学科」
- 标题最多两行，超出省略；悬停显示完整标题
- 名师头像带金色描边；作者名后不带认证标

交互：
- 点卡片 → 进该资源详情页
- 其余交互见 demo

[!] demo 里点任意卡片都进入同一个示例资源，上线应进入卡片对应的资源

规则：
- 推荐及各场景页签：展示推荐内容，按当前分类 / 筛选过滤
- 关注：未选头像 → 全部关注对象的资源和应用，同一资源只出现一次；选中头像 → 只展示该作者的
- 列数随可用宽度变化：窄屏 1 列 → 2 列 → 3 列 → 超宽 4 列
- 标题只有一行时仍占两行高度，同排卡片底边对齐
- 推荐首屏加载 20 条，触底自动加载 +20 条，全部加载完底部显示「没有更多了」；关注的条数沿用线上

[!] demo 为一次性全量展示（推荐 10 条、关注 12 条），无分页；推荐条数与触底加载为建议值，上线前与研发确认

[!] 推荐排序规则，待定

异常 / 空状态：
- 筛选无结果 → 空状态「这个组合下还没有内容」+「换个场景或清除筛选看看」
- 关注下无结果 → 见模块 3
- 首屏加载失败 → 卡片区「加载失败，点击重试」
- 触底加载失败 → 底部「加载失败，点击重试」，已加载卡片保留
- 封面加载失败 → 占位底色 + 标题首字兜底，卡片不塌；占位样式设计待补
- 作者无头像 → 显示名字首字
- 作者名过长 → 单行省略
- 点卡片时资源已下架 → toast「该资源已下架」，停留本页并移除该卡片
