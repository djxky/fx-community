# 教师主页

> 版本 v1.4 · 教师社区

## 1. 个人资料区 [UPDATED]

展示（主态、客态同一版式）：
- 头像、姓名；姓名后：认证标、创作者标识（有才显示）
- 一行简介（名师：任职 · 方向；普通老师：学科 · 学段 · 自我介绍）
- 标签行（有才显示）：平台荣誉在前（金色，如「2025 年度名师」「百大名师 · 数学」），本人资质在后（灰色，如「数学特级教师」「正高级教师」），两组间竖线分隔
- 数据：客态「被使用 · 被收藏」；主态「被使用 · 被收藏 · 关注 · 关注者」，四个数字同一样式
- 按钮：客态「+ 关注」；主态「编辑资料」「分享主页」
- 主态姓名后额外展示 ID

交互：
- 分享主页 → 进「分享名片」页
- 关注、编辑资料：demo 无响应

[!] 关注后的按钮状态、取消关注流程待定
[!] 编辑资料是进独立页还是弹窗，待定

规则：
- 主态比客态只多「关注 · 关注者」，其余数据一致
- 被使用 = 改编、保存副本、下载过该老师作品的老师人数；同一位老师对同一作品多次使用只算一次
- 被收藏 = 该老师所有作品的收藏数之和，与作品卡、资源详情页的收藏数一致
- 改编已计入被使用，不单独展示「被改编」
- 被改编、被下载、保存副本等分项创作数据不在主页展示，在「创作者中心」查看
- 关注 = 我关注的人数；关注者 = 关注我的人数；仅主态展示
- 简介只展示一行，超长末尾省略，不换行
- 数字：不足 1 万显示千分位（1,240）；满 1 万显示「X.X万」
- 标签只放身份与荣誉；使用量、改编量这类由数据得出的称号不做标签
- 看自己的主页 → 不显示关注，显示编辑资料、分享主页

[!] 标签上限待定（建议平台荣誉 ≤ 2、本人资质 ≤ 3，其余进「关于」）
[!] 被使用跨作品是否去重（同一位老师用了该老师 3 个作品算 1 人还是 3 人），待定
[!] 主态点「关注 / 关注者」是否进关注列表页，待定（demo 不可点）
[!] 客态是否展示 ID 待定（线上客态展示，demo 仅主态）

异常：
- 头像加载失败 / 未上传 → 姓名首字兜底；样式设计待补
- 简介为空 → 该行不展示，不占位
- 无认证 → 不显示认证标
- 无标签 → 标签行不展示，不占位
- 姓名超长 → 单行省略；上限设计待补
- 数据为 0 → 显示「0」，不隐藏（含主态「0 关注」「0 关注者」）
- 未登录点关注 → 引导登录，登录后自动完成关注
- 关注失败 → toast「关注失败，请重试」，按钮恢复


## 2. 页签 [UPDATED]

展示（主态、客态一致）：作品 N · 技能 N · 专题 N · 关于

交互：交互见 demo（点页签切换内容，页面回到顶部）。

规则：
- 默认选中「作品」
- 数字 = 该老师公开的作品 / 技能 / 专题数量
- 主态新建、删除专辑后，「专题」数字实时变化
- 数量为 0 → 页签照常显示（如「技能 0」），进入后展示空状态


## 3. 作品 [UPDATED]

展示：作品卡网格（不含技能），每卡：
- 封面（左上角类型标：教案 / 课件 / 应用）
- 标题
- 一行推荐信息（三选一）：编辑精选标 / 一句话描述 / 本月热门趋势
- 作者：头像 + 名称 · 机构
- 底栏：✓ N 位老师使用 · ☆ 收藏数

交互：点作品卡 → 进资源详情页

规则：
- 技能不在「作品」里，进「技能」页签
- 排序：demo 为固定顺序

[!] 排序规则待定（按发布时间 / 使用人数 / 老师置顶）
[!] 加载量待定：demo 无分页。建议首屏 12 条、触底自动加载 +12、加载完显示「没有更多了」
[!] 封面 demo 为色块 + 类型图标，正式版是否用作品真实封面待定
[!] 主态作品含「副本《…》」「改编《…》」：保存的副本是否在客态展示、改编作品是否标出原作，待定

异常：
- 客态无作品 → 空状态「TA 还没有发布作品」
- 主态无作品 → 空状态「还没有作品，去创作第一个吧」；插图设计待补
- 封面加载失败 → 类型色块 + 类型图标兜底，卡片不塌
- 标题超长 → 省略；行数设计待补
- 无推荐信息 → 该行不展示，卡片高度对齐方式设计待补
- 作品已下架 / 删除 → 客态不展示；主态展示方式待定
- 加载失败 → 列表区「加载失败，点击重试」


## 4. 技能 [UPDATED]

展示（主态、客态一致）：技能卡，字段同「作品」，类型标为「技能 · Skill」。

交互：点技能卡 → 进技能详情页。

规则：加载量同「作品」。

异常：
- 客态无技能 → 空状态「TA 还没有发布技能」
- 主态无技能 → 空状态「还没有技能」；插图设计待补
- 加载失败 → 「加载失败，点击重试」


## 5. 专题

展示：
- 顶部一句说明：「把一个个作品组织成成体系的专题——像开一门课,一讲接一讲。老师自己命名、自己排序。」
- 主态：说明下方「新建专辑」入口，其下为我的专辑列表
- 专辑卡：专辑名、类型 · 讲数 · 使用数、一句简介（有才显示）、「查看专题 ›」、讲次列表（第 N 讲、封面、作品名、类型）
- 主态专辑卡右上「···」管理菜单：编辑专辑、上移、下移、删除专辑

交互：
- 点专辑卡 → demo 跳资源详情页
- 点「新建专辑」→ 打开新建弹窗（模块 6）
- 编辑专辑 → 打开同一弹窗，预填名称、简介、已选作品和讲次顺序（模块 6）
- 上移 / 下移 → 与相邻专辑互换位置，立即生效
- 删除专辑 → 确认框（见异常）→ 点「删除」移除该专辑，toast「专辑已删除」
- 菜单打开时点页面任意处 / 按 Esc → 只收起菜单，不进详情

规则：
- 专辑顺序由老师调整；客态按老师排好的顺序展示
- 新建的专辑放在列表最前
- 第一个专辑「上移」置灰，最后一个「下移」置灰
- 讲数 = 专辑内作品数；使用数 = 专辑内作品使用人数之和
- 类型 = 专辑内作品类型去重，用「+」连接（如「应用+技能」）
- 删除专辑只解散分组，作品仍在「作品」/「技能」页签

[!] 点专辑卡应进专题合集页，demo 目前跳资源详情页；点其中某一讲是进该讲详情还是同样进合集页，待定
[!] 页签叫「专题」、按钮叫「新建专辑」，名称待统一
[!] 顶部说明对客态是否展示待定
[!] 专辑封面：老师上传 / 自动取第 1 讲封面，待定
[!] 可见范围：创建即公开，还是支持草稿 / 仅自己可见，待定
[!] 删除后是否支持撤销，待定
[!] 讲次列表 demo 横向滚动全部展示，是否限制展示数量待定

异常：
- 删除确认 → 「删除专辑「专辑名」？」+「专辑里的作品不会被删除，只是不再成组展示在主页上。」，按钮「取消 / 删除」
- 客态无专题 → 空状态「暂无专题」
- 主态无专辑（含全部删除后）→ 只展示说明 +「新建专辑」入口
- 专辑内作品被删除 / 下架 → 该讲不展示，讲数、使用数同步减少
- 专辑内作品全部失效 → 客态不展示该专辑；主态保留并提示「专辑内作品已全部失效」，样式设计待补
- 调整顺序 / 删除失败 → toast「操作失败，请重试」，列表恢复原状
- 专辑名超长 → 单行省略


## 6. 新建 / 编辑专辑弹窗（仅主态）

展示：两步，步骤条「1 填信息 · 2 选作品、排讲次」；标题新建为「新建专辑」、编辑为「编辑专辑」；副标题「专辑 = 把你已有的作品，按一门课的顺序打包成一个系列，挂在你的主页上。」
- 第 1 步：专辑名称（占位「例：古文沉浸式漫游 系列」）、一句简介（选填，占位「这门课讲什么、适合谁上」）
- 第 2 步：「从我的作品里挑」「已选 N 个」、搜索框（占位「搜索我的作品…」）、作品网格（封面、标题、类型 · N 位老师使用、勾选标）、讲次顺序列表（第 N 讲、作品名、↑、↓、✕）

交互：
- 下一步 / 上一步 / 勾选作品 / 搜索：交互见 demo
- 讲次：勾选顺序即讲次顺序；↑ ↓ 调整；✕ 移出专辑并取消勾选
- 新建点「创建专辑」→ 关闭弹窗，专辑出现在列表最前，toast「专辑已创建 · 已加入你的主页」
- 编辑点「保存修改」→ 关闭弹窗，专辑原位更新，toast「专辑已更新」
- 关闭（× / 取消 / 点遮罩 / Esc）：没有改动直接关闭；有改动先确认（见异常）

规则：
- 名称必填，最多 20 字；简介选填，最多 40 字
- 名称去掉首尾空格后，不能与我的其它专辑重名
- 至少选 1 个作品
- 可选范围 = 我的全部作品（含技能）
- 搜索按作品标题匹配
- 第 1 讲「↑」置灰，最后一讲「↓」置灰

[!] 一个专辑最多放多少个作品，待定

异常：
- 名称为空 → 「下一步」置灰；点击提示「请填写专辑名称」
- 名称重名 → 点「下一步」提示「已有同名专辑，换个名字吧」
- 名称 / 简介达到字数上限 → 不可再输入
- 未选作品 → 「创建专辑 / 保存修改」置灰；点击提示「至少选 1 个作品」
- 未选作品时讲次列表 → 「勾选作品后，按勾选顺序排成第 1 讲、第 2 讲…」
- 我没有作品 → 网格「还没有作品，先去创作吧」
- 搜索无结果 → 「没有找到相关作品」
- 新建时有内容就关闭 → 确认「放弃新建专辑？」+「已填内容不会保存。」，按钮「取消 / 放弃」
- 编辑时有改动就关闭 → 确认「放弃修改？」+「修改的内容不会保存。」
- 只多打了空格 → 视为没有改动，直接关闭
- 保存失败 → toast「保存失败，请重试」，弹窗保留已填内容和勾选


## 7. 关于

展示：
- 专家简介（正文）
- 四组清单：荣誉与称号、学术成果、社会兼职、代表成果

规则：
- 某组无内容 → 该组不展示
- 简介全文展示，不折叠

[!] 主态「关于」demo 展示的是示例名师内容；主态的字段与编辑入口待定

异常：
- 全部为空 → 客态空状态「TA 还没有填写个人介绍」；主态「完善个人介绍，让更多老师认识你」
- 加载失败 → 「加载失败，点击重试」


## 页面级异常

- 未登录 → 可正常浏览他人主页；点关注时引导登录
- 老师不存在 / 已注销 → 整页空状态「该用户不存在或已注销」；插图设计待补
- 页面加载失败 → 整页「加载失败，点击重试」
- 网络断开 → toast「网络异常，请重试」

[!] 账号被封禁时的客态展示待定

## 主客态差异

版式、页签两态一致，只有以下不同：

| 区域 | 客态（看别人） | 主态（我的主页） |
|---|---|---|
| 入口 | 点作者名 / 名师卡等进入 | 头像菜单「我的主页」 |
| 资料区按钮 | 关注 | 编辑资料、分享主页 |
| 关注 · 关注者 | 不展示 | 展示，与被使用、被收藏同一样式 |
| ID | demo 不展示 | 展示 |
| 新建专辑 | 无 | 有 |
| 专辑管理（编辑 / 排序 / 删除） | 无 | 有 |
