# 排行榜

> 版本 v1.0 · 教师社区

## 1. 顶部栏

展示：「排行榜」「发现」两个 Tab（当前为排行榜）；右侧搜索框，占位文案「搜知识点、课型、课件、教案…」。

交互：点「发现」→ 切到发现页。

异常：
[!] 搜索框在 demo 中点击无响应，点击后跳搜索页还是就地展开，待确认


## 2. 编辑推荐

展示：推荐卡 2 张，每张：封面、作品标题、一句推荐语、作者（头像 + 名字，有身份时带身份徽标，如「特邀专家」）、使用数「N 位老师使用」。

交互：点卡片 → 进该作品详情页。

规则：
- 编辑人工精选，只推荐作品，不推荐创作者本人
- 固定 2 张，不受任何学科 / 周期筛选影响

异常：
- 推荐资源已下架 → 该卡不展示，另一张单独展示
- 无推荐内容 → 区域显示「暂无内容」
[!] 只剩 1 张时是否撑满整行，待设计确认
[!] 推荐语超长时最多显示几行，demo 未限制，待设计确认


## 3. 课堂使用榜

展示：
- 标题右侧：学科下拉、周期切换（本周 / 本月 / 年度）
- 前 3 名大卡：封面、作品标题、一句话简介、作者、使用数
- 第 4–9 名两列列表：缩略图、作品标题、一句话简介、作者、使用数

交互：点大卡 / 列表行 → 进该作品详情页；切学科、切周期交互见 demo。

规则：
- 按所选周期内的使用人数倒序
- 默认：全部学科 · 本周
- 共展示 9 条（3 张大卡 + 6 行），无加载更多、无「查看全部」

异常：
- 筛选后不足 9 条 → 按实际条数展示；不足 3 条时只出对应张数的大卡，列表不出
- 筛选后 0 条 → 见文末「学科筛选无结果」
[!] demo 中切换本周 / 本月 / 年度，榜单内容不变，三个周期的数据待接入
[!] 只有 1–2 张大卡时，卡片保持三栏宽度、右侧留空，是否需要撑满待设计确认


## 4. 每周热门

展示：学科下拉；作品卡 6 张，每张：封面、作品标题、作者、使用数。

交互：点卡片 → 进该作品详情页。

规则：
- 按本周使用人数倒序，与上架时间无关
- 默认全部学科
- 展示 6 条，无加载更多
- 每行列数随页面宽度 1–4 列自适应

异常：
- 筛选后不足 6 条 → 按实际条数展示
- 筛选后 0 条 → 见文末「学科筛选无结果」
[!] 页面很宽、每行 4 列时，6 张卡会出现不满的第二行（4 + 2），待设计确认


## 5. 优质改编

展示：学科下拉；两列列表 8 条，每行：缩略图、改编作品标题、改编者（头像 + 名字）、使用数。

交互：点行 → 进该改编作品详情页。

规则：
- 只收改编作品，按改编作品的使用人数倒序
- 默认全部学科
- 展示 8 条，无加载更多

异常：
- 筛选后不足 8 条 → 按实际条数展示
- 筛选后 0 条 → 见文末「学科筛选无结果」
[!] 列表不展示原作信息（原作名 / 原作者），是否需要待确认


## 6. 创作达人榜

展示：创作者卡 6 张（两行三列），每张自上而下：
- 创作者头像 + 名字
- 数据「累计使用数 位老师使用 · 作品数 件作品」，如「4.6万 位老师使用 · 18 件作品」
- 代表作封面、代表作名称

交互：点卡片 → 进代表作详情页（不进老师主页）。

规则：
- 按作品数与累计使用人数综合排序
- 无学科筛选、无周期切换
- 展示 6 位

异常：
[!] 综合排序中作品数与使用人数的权重待定
[!] 创作者没有可展示的代表作（如代表作已下架）时，是否下榜或换一部代表作，待确认


## 7. 新锐创作者榜

展示：
- 前 3 名创作者卡：创作者头像 + 名字、使用数「N 位老师使用」、代表作封面、代表作名称
- 第 4–9 名两列列表：代表作缩略图、代表作名称、创作者（头像 + 名字）、使用数

交互：点卡片 / 列表行 → 进代表作详情页（不进老师主页）。

规则：
- 只收入驻不久的新人
- 按近 30 天代表作被使用人数倒序
- 无学科筛选、无周期切换
- 共展示 9 条（3 张卡 + 6 行），无加载更多

异常：
- 符合条件的新人不足 9 位 → 按实际人数展示；不足 3 位时只出对应张数的卡，列表不出
[!] 「新人」门槛（入驻多久、首发多久内）待定
[!] 卡上的使用数未标注「近 30 天」，是否需要标注待确认


## 通用规则（各榜单共用）

- 名次：不显示序号，不压名次角标；排名由从左到右、从上到下的顺序表达
- 封面上不压任何标签
- 使用数：不足 1 万显示完整数字（如 8,900）；满 1 万显示「x.x万」（如 4.6万、10万）；满 1 亿显示「x.x亿」；保留一位小数，末尾 .0 省略
- 所有榜单条目点击都进作品详情页，创作者榜也不进老师主页
- 标题 / 名字超长 → 单行省略

学科筛选（课堂使用榜、每周热门、优质改编各一个）：
- 选项：全部学科 · 语文 · 数学 · 英语 · 物理 · 化学 · 信息科技 · 音乐 · 体育
- 各榜单独立筛选，互不联动
- 按作品所属学科筛选

异常 / 空状态：
- 榜单无内容（非筛选导致，如本期暂无数据）→ 榜单区显示「暂无内容」
- 学科筛选无结果 → 榜单区显示「{学科}学科暂未上榜」+「换个学科看看本期内容」
- 条目对应的资源不存在 / 已下架 → toast「该资源暂不可用」，停留在排行榜
- 封面 / 缩略图加载失败 → 占位底色 + 作品标题首字兜底，卡片不塌；占位样式设计待补
- 创作者头像缺失 → 显示名字首字
- 榜单加载中 → 占位骨架；样式设计待补
- 单个榜单加载失败 → 该榜单区域显示「加载失败，点击重试」，不影响其他榜单
[!] demo 中部分条目对应的资源不存在，点击无任何反应（如「一盘菜讲懂算法流程」），上线前需补数据或按上面的 toast 处理
