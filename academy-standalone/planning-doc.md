## 实施原则

- 保留当前 DOM、radio/checkbox 交互和业务接口，只改九项所需的结构或样式。
- 新增或修改的颜色只引用宿主 main 主题三个 v3 文件中语义、用途匹配的 token。
- 设计 SVG 必须先取得原始资源并保存到相邻 `assets` 目录，再由源码引用；无法取得时该项停止，不重绘、不热链。
- 生产代码补充说明业务目的、状态切换和兼容边界的注释。
- 新增 CSS/JS 保持 Chrome 86 可用，不引入 `inset`、容器查询等更晚能力作为唯一实现。
- 后续先补针对性回归测试，再实现，再做独立源码与宿主 iframe 的 Chrome 验证；不自动运行宿主完整 `npm run build`。
- 本轮不执行 Git 状态读取、提交、推送或部署。
